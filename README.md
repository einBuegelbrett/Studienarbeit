# Studienarbeit - Bewegungserkennung mit Sensordaten

Projektziel

Ziel dieses Projekts ist es, Bewegungen des menschlichen Körpers (z. B. Gehen, Stehen, Rennen) mithilfe eines Arduino Nano 33 BLE Rev2 und eines Raspberry Pi 4 zu erfassen, zu speichern und maschinell zu klassifizieren. Die Daten werden mittels IMU-Sensoren (Beschleunigung, Gyroskop etc.) erfasst, aufbereitet, visualisiert und anschließend mit ML-Modellen ausgewertet. Dabei streben wir eine Klassifikationsgenauigkeit von mindestens 80 % an.

# Struktur & Regeln für die Zusammenarbeit (GitHub)
Pull Requests

    Jede Änderung erfolgt über Pull Requests.
    
    Kurze, prägnante Beschreibung der Änderung im PR-Text notwendig.
    
    Jeder Pull Request, hängt an ein Issue um Bearbeitung nachvollziehen zu können und Issues zu managen.
		
Issues

    Fehlende Aspekte, offene Fragen oder To-dos immer als GitHub-Issue anlegen.
		
    Titel, Beschreibung und passende Labels (z. B. methodisch, technik, vergleich, dokumentation) verwenden.
		
    Falls möglich, direkt mit Sub-Issues für Teilaspekte aufteilen.
		
Branches

    Jeder Arbeitet auf ein Branch mit den Namen "[INITIALS]_[ISSUENR]_[commitmessage] bsp. AC_#16_feat: Erste Ideen für Sampling Sizes gesammelt und aufgeschrieben
		
    Falls der Branch nicht mehr genutzt wird löschen nach dem es gemerged wurde
		
Kommentare

    Kommentare in Issues dienen zur Diskussion, Zwischenständen und Aufgabenverteilung.
		
    Fortschritte und Entscheidungen bitte dort dokumentieren, um spätere Bearbeitung des Textes zu vereinfachen da Infos zwischengespeichert sind.
